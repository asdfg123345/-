# 🍅 零食番茄钟 · 手账贴纸风

一个纯前端（HTML + CSS + JavaScript，零依赖）的番茄钟计时器，手账贴纸风格，适合专注学习与工作。

## ✨ 功能

- 🕒 **卡通番茄表盘**：红色番茄 SVG 背景 + 卡通表情（眼睛 / 腮红 / 微笑）
- ⏱ **三根彩色指针**：
  - 时针 🔴 番茄红 — 表示阶段整体进度
  - 分针 🔵 皇家蓝 — 已流逝分钟平滑过渡
  - 秒针 🟡 金黄渐变 — `requestAnimationFrame` 毫秒级平滑扫秒
- 🎨 **手账贴纸风数字时间**：三段式胶囊容器 — 分钟（可可棕）+ 冒号（呼吸闪烁）+ 秒（皇家蓝）
- 📋 **事件规划表**：4 轮番茄循环，每轮可写本轮任务，`localStorage` 自动持久化
- ✏️ **阶段进度环**：`conic-gradient` 随指针同步增长
- 🎀 **零食贴纸解锁系统**：每完成一轮专注解锁一个零食贴纸
- 🎉 **撒花特效 + 阶段切换音效**
- 🌱 **响应式**：桌面 / 平板 / 手机自动适配
- 🔧 **可配置**：专注 / 短休 / 长休时长滑块

## 🚀 快速开始

直接用浏览器打开 `零食番茄钟_手账贴纸风_v1.html` 即可使用。

或用 Python 起一个临时服务器（避免某些浏览器 file:// 限制）：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000/零食番茄钟_手账贴纸风_v1.html

## 🛠 技术栈

- **纯原生** HTML5 / CSS3 / JavaScript (ES2017+)
- **零外部依赖**，无构建步骤
- **requestAnimationFrame** 平滑计时驱动
- **localStorage** 持久化任务输入
